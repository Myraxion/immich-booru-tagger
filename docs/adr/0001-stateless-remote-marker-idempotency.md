# 无本地状态的远端幂等标记架构

系统不在本地维护 SQLite 数据库、缓存文件或处理检查点，而是完全依托写回至 Immich 资产上的 `meta/booru_tagged` 层级标签（Processed Marker）作为增量过滤与重复执行幂等性的唯一事实来源，并以微批次（Micro-batch）为单位同步落库业务标签与幂等标记。

这样设计避免了本地状态与 Immich 远端真实数据（如用户在 Immich 中手动删改标签、跨机器运行脚本、容器无状态部署）产生状态撕裂，同时通过微批次提交将中途异常中断的重算代价控制在单个微批次以内。在需要全量重算（`--force`）时，系统仅清理受管命名空间（`rating/`, `copyright/`, `character/`, `general/`, `meta/`, `artist/`）下的旧标签，保护用户自定义标签不受破坏。
